# KR-Chart-Scanner

한국 주식에서 기술적 분석 기준으로 매수 후보를 자동 탐색하기 위한 프로젝트입니다.

## 현재 목표

첫 번째 버전은 **추세전환형(Reversal)** 스캐너입니다.

검증 기준일은 일진전기(103590) `2026-09-04`이며, 해당 날짜 이후의 데이터는 사용하지 않습니다. 먼저 이 날짜를 높은 점수로 포착할 수 있는지 확인하고, 이후 전체 종목과 여러 시장 국면에서 백테스트해 과최적화를 검증합니다.

현재 점수 요소는 다음과 같습니다.

- 최근 Swing Low가 이전 Swing Low보다 높은지
- 20일 이동평균 상승 여부
- 60일 이동평균 평탄화 또는 상승 여부
- 20일선과 60일선 수렴 여부
- 현재가의 20일선, 60일선 접근 여부
- RSI 45~65 여부
- KOSPI 대비 20일 상대수익률
- 상대강도 비율의 최근 방향
- 상승일 대비 조정일 거래량
- 이전 60일 고점까지의 상승 여력

점수 가중치는 임시값입니다. 향후 백테스트 결과에 따라 수정합니다.

## 설치

```bash
python -m venv .venv
```

Windows PowerShell:

```bash
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 첫 테스트

```bash
python main.py --ticker 103590 --as-of 2026-09-04
```

프로그램은 해당 날짜까지의 데이터만 내려받고, 추세전환 점수와 각 조건의 PASS/FAIL을 출력합니다.

다른 종목이나 날짜도 같은 방식으로 확인할 수 있습니다.

```bash
python main.py --ticker 005930 --as-of 2026-10-06
```
